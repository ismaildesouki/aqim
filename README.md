# Aqim website

The public support and privacy pages for Aqim, the iOS prayer companion app.
Served by GitHub Pages at https://ismaildesouki.github.io/aqim/

- `support.html`: the App Store support URL
- `privacy.html`: the App Store privacy policy URL
- `index.html`: the App Store marketing URL

Plain HTML and one stylesheet. No scripts, cookies or analytics.
